# Drill #9: 소년 상하좌우 이동 및 방향 바꾸기

2D 게임 프로그래밍 (2DGP) Drill #9 실습 과제 구현 저장소입니다.

## 1. 개발 개요 및 목표
- **과제 목표**: 키보드 입력을 통해 소년 캐릭터의 상하좌우 이동 및 방향 전환을 구현하고, 애니메이션 프레임 제어와 화면 경계 제한 처리 수행
- **사용 리소스**:
  - 캐릭터 스프라이트 시트: `animation_sheet.png` (802 x 402)
  - 배경 이미지: `TUK_GROUND.png` (1280 x 1024)

---

## 2. 세부 기능 기획 및 구현 내용

### 1) 상하좌우 키보드 입력 처리
- `SDL_KEYDOWN` 및 `SDL_KEYUP` 이벤트를 분리하여 키 상태를 실시간 추적
- `dir_x`, `dir_y` 방향 변수(-1, 0, 1)를 이용해 부드러운 연속 이동 및 대각선 동시 이동 지원
- 반대 방향 키를 동시에 누를 경우 상쇄되어 정지 상태 유지

### 2) 애니메이션 상태 관리 (`action` & `facing`)
- 스프라이트 시트의 4가지 동작 행 연동:
  - `action = 0`: 왼쪽 달리기 (Run Left, y = 0)
  - `action = 1`: 오른쪽 달리기 (Run Right, y = 100)
  - `action = 2`: 왼쪽 정지 (IDLE Left, y = 200)
  - `action = 3`: 오른쪽 정지 (IDLE Right, y = 300)
- `facing` 변수(1: 우측, -1: 좌측)를 통해 마지막으로 이동했던 수평 방향 기억
- 키 입력이 없는 정지(IDLE) 상태 시 바라보던 방향에 맞는 IDLE 모션 전환
- 수직(위/아래)으로만 이동 시 기존에 바라보던 좌우 방향의 달리기 모션 유지

### 3) 화면 경계 제한 (Boundary Clamping)
- `pico2d.clamp` 함수를 적용하여 소년 캐릭터(100x100)가 1280x1024 해상도의 배경 밖으로 나가지 않도록 좌표 제한
- 수평 범위: `50 <= x <= 1230`
- 수직 범위: `50 <= y <= 974`

### 4) 게임 루프 구조화
- LEC 10 강의 슬라이드 권장 구조 적용:
  - `handle_events()`: 이벤트 수집 및 방향 입력 처리
  - `update_character()`: 캐릭터 좌표 이동, 경계 체크, 애니메이션 및 액션 갱신
  - `render_world()`: 배경 및 캐릭터 프레임 렌더링
